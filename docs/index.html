To-Do List Project

Theme: To-Do List. A small Python project with unit tests (pytest), GitHub Actions CI and GitHub Pages. Course: CSC3324, Assignment 2.

Team

  • Fatima Ezzahra Ghezala (fatimaezzahra456): task management
  • Hafsa El Mahfoudy (Hafsa-mhf): filter and search
  • Chaimae Tahir (chaimaetahir): statistics

Implemented features

  • Task management: add a task (empty titles are rejected) and mark a task as done.
  • Filter and search: filter tasks by status and search by keyword (case-insensitive).
  • Statistics: completion percentage and number of pending tasks.

How to run the project

git clone https://github.com/fatimaezzahra456/To-do-list-project.git
cd To-do-list-project
pip install -r requirements.txt
pytest
